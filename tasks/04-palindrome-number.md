# Palindrome Number

Write `is_palindrome(x: int) -> bool` that returns True if `x` reads the same
forwards and backwards (as a decimal integer, ignoring the sign).

## Examples

```
is_palindrome(121) == True
is_palindrome(-121) == False
is_palindrome(10) == False
is_palindrome(0) == True
```

## Constraints

- `-2^31 <= x <= 2^31 - 1`
- Negative numbers are not palindromes
